# Past versions

This folder holds the earlier versions of ideas that were revised. The file
`versions/<id>/v<N>.md` is the idea file exactly as it was at version N. The latest version
of every idea is in [`ideas/`](../ideas/).

Files here are written once by `python -m out_of_tokens revise` and never edited again. The
site shows them at `/ideas/<id>/v<N>/`. See "Revise an idea" in
[CONTRIBUTING.md](../CONTRIBUTING.md).
